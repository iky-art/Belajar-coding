Apa Itu JavaScript?

JavaScript adalah bahasa yang bikin website jadi hidup. Kalau HTML itu kerangka dan CSS itu baju, JavaScript itu otaknya.

Dengan JavaScript, kamu bisa bikin tombol yang bisa diklik, nampilin pesan, ngubah teks, dan banyak lagi.

Contoh JavaScript Sederhana

// Nampilin pesan pop-up alert("Halo!"); // Nampilin pesan di console (F12) console.log("Pesan rahasia"); // Ngubah teks di halaman document.getElementById("demo").innerHTML = "Teks berubah";

Coba Sendiri

Klik tombol di bawah:

Teks ini bakal berubah
// Hasil muncul di sini

Latihan

Buat JavaScript untuk:

"Tampilkan alert dengan tulisan 'Selamat Belajar!'"
