⚡ JavaScript = Otak Website

JavaScript adalah bahasa pemrograman yang membuat website menjadi hidup dan interaktif. Kalau HTML itu kerangka dan CSS itu baju, maka JavaScript adalah otak yang menggerakkan semuanya!

📌 Apa yang Bisa Dilakukan JavaScript?

  • Menampilkan alert (pesan pop-up)
  • Mengubah isi teks di halaman
  • Menanggapi klik tombol
  • Menghitung angka
  • Memvalidasi form (cek input)
  • Membuat animasi sederhana

📌 Cara Menulis JavaScript

// Cara 1: Di dalam tag <script>
<script>
    alert("Halo Dunia!");
</script>

// Cara 2: Di file terpisah (script.js)
// Dipanggil dengan: <script src="script.js"></script>
console.log("Pesan di console");

💻 Contoh JavaScript Sederhana

// Menampilkan pesan pop-up
alert("Selamat datang!");

// Menampilkan pesan di console (F12)
console.log("Ini pesan di console");

// Mengubah teks di halaman
document.getElementById("demo").innerHTML = "Teks berubah!";

// Menghitung penjumlahan
let a = 10;
let b = 5;
let hasil = a + b;
alert("Hasil: " + hasil);
