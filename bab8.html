Perulangan (Loop)

← Bab 7 🏠 Home Bab 9 →

🔄 Perulangan = Mengulang Tugas

Perulangan (Loop) digunakan untuk mengulang kode beberapa kali. Kayak mengulang gerakan di senam atau mengulang bacaan di sekolah!

📌 Kapan Butuh Perulangan?

  • Mencetak angka 1 sampai 100
  • Menampilkan data siswa satu per satu
  • Menghitung total semua nilai
  • Membuat game yang berulang sampai menang

📌 Struktur FOR

FOR digunakan jika kita tahu berapa kali harus mengulang.

for (inisialisasi; kondisi; increment) {
    // Kode yang diulang
}

// Contoh: Cetak angka 1 sampai 5
for (int i = 1; i <= 5; i++) {
    System.out.println("Angka: " + i);
}

// Output:
// Angka: 1
// Angka: 2
// Angka: 3
// Angka: 4
// Angka: 5

Penjelasan:
• inisialisasi: int i = 1 (mulai dari 1)
• kondisi: i <= 5 (ulangi selama i ≤ 5)
• increment: i++ (tambah 1 setiap kali)

📌 Struktur WHILE

WHILE digunakan jika kita tidak tahu pasti berapa kali harus mengulang.

while (kondisi) {
    // Kode yang diulang
}

// Contoh: Cetak angka 1 sampai 5
int i = 1;
while (i <= 5) {
    System.out.println("Angka: " + i);
    i++; // Jangan lupa tambah!
}

// Output: sama seperti FOR di atas

⚠️ Peringatan! Jangan lupa menambah i++ di dalam WHILE, kalau tidak program akan loop selamanya!

📌 Struktur DO-WHILE

DO-WHILE selalu menjalankan kode minimal 1 kali.

do {
    // Kode yang diulang
} while (kondisi);

// Contoh: Cetak angka 1 sampai 5
int i = 1;
do {
    System.out.println("Angka: " + i);
    i++;
} while (i <= 5);

💻 Contoh Perulangan dalam Program

// 1. Menghitung total nilai
int[] nilai = {80, 85, 90, 75, 88};
int total = 0;

for (int i = 0; i < nilai.length; i++) {
    total = total + nilai[i];
}
System.out.println("Total: " + total);

// 2. Mencetak tabel perkalian
for (int i = 1; i <= 10; i++) {
    for (int j = 1; j <= 10; j++) {
        System.out.print(i * j + "\t");
    }
    System.out.println();
}

// 3. Mencetak pola bintang
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print("*");
    }
    System.out.println();
}

📊 Perbandingan FOR, WHILE, DO-WHILE

JenisKapan DipakaiMinimal Jalan
FORTahu pasti berapa kali0 kali
WHILETidak tahu pasti, cek di awal0 kali
DO-WHILEHarus jalan minimal 1 kali1 kali

✏️ Latihan Perulangan

Buatlah perulangan untuk:

"Mencetak angka genap dari 2 sampai 10"

// Cara 1: Dengan FOR
for (int i = 2; i <= 10; i += 2) {
    System.out.println(i);
}

// Cara 2: Dengan WHILE
int i = 2;
while (i <= 10) {
    System.out.println(i);
    i += 2;
}

// Output:
// 2
// 4
// 6
// 8
// 10
