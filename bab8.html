Perulangan (Loop)

← Bab 7 Home Bab 9 →

Apa Itu Perulangan?

Perulangan dipakai buat mengulang-ulang kode beberapa kali. Kayak kamu ngulang gerakan senam atau ngulang baca doa.

Struktur FOR

for (int i = 1; i <= 5; i++) { System.out.println("Angka: " + i); } // Output: 1, 2, 3, 4, 5

Penjelasan:
i = 1 (mulai), i <= 5 (syarat), i++ (tambah 1 setiap kali)

Struktur WHILE

int i = 1; while (i <= 5) { System.out.println("Angka: " + i); i++; } // Output: 1, 2, 3, 4, 5

Peringatan: Jangan lupa i++, kalau nggak bakal loop selamanya!

Kapan Pakai Yang Mana?

Jenis Kapan Dipakai
FOR Kalau tahu pasti berapa kali
WHILE Kalau nggak tahu pasti, dicek di awal
DO-WHILE Harus jalan minimal 1 kali

Latihan

Buat perulangan untuk:

"Mencetak angka genap dari 2 sampai 10"

for (int i = 2; i <= 10; i += 2) { System.out.println(i); } // Output: 2, 4, 6, 8, 10
