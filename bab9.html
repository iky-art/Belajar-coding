PBO (Class & Object)

Apa Itu PBO?

PBO itu Pemrograman Berorientasi Objek. Intinya ada Class (cetakan) dan Object (hasil cetakan).

Bayangin cetakan kue. Class itu cetakannya, Object itu kue yang udah jadi. Dari satu cetakan bisa bikin banyak kue.

Class Sederhana

class Siswa { // Atribut String nama; int umur; // Constructor Siswa(String nama, int umur) { this.nama = nama; this.umur = umur; } // Method void perkenalan() { System.out.println("Halo, saya " + nama); } }

Bikin Object

// Buat object dari class Siswa Siswa budi = new Siswa("Budi", 17); budi.perkenalan(); // Output: Halo, saya Budi Siswa ani = new Siswa("Ani", 16); ani.perkenalan(); // Output: Halo, saya Ani

Method dengan Return

class Calculator { int tambah(int a, int b) { return a + b; } } Calculator calc = new Calculator(); int hasil = calc.tambah(10, 5); System.out.println(hasil); // Output: 15

Latihan

Buat class untuk:

"Class Buku dengan judul, penulis, dan method tampilkanInfo()"

class Buku { String judul; String penulis; Buku(String judul, String penulis) { this.judul = judul; this.penulis = penulis; } void tampilkanInfo() { System.out.println("Judul: " + judul); System.out.println("Penulis: " + penulis); } }
