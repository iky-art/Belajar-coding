🏗️ PBO = Cetakan & Hasil Cetakan

PBO (Pemrograman Berorientasi Objek) adalah cara membuat program dengan class (cetakan) dan object (hasil cetakan).

📌 Analogi Class & Object

  • Class = Cetakan kue (resep)
  • Object = Kue yang sudah jadi
  • Dari 1 cetakan bisa dibuat banyak kue
  • Setiap kue punya rasa dan bentuk yang sama

📌 Struktur Class di Java

class NamaClass {
    // 1. Atribut (data / properti)
    String nama;
    int umur;

    // 2. Constructor (pembuat object)
    NamaClass(String nama, int umur) {
        this.nama = nama;
        this.umur = umur;
    }

    // 3. Method (perilaku / fungsi)
    void tampilkan() {
        System.out.println("Nama: " + nama);
        System.out.println("Umur: " + umur);
    }
}

💻 Contoh Class Sederhana: Siswa

// 1. Buat Class
class Siswa {
    // Atribut
    String nama;
    int umur;
    String kelas;

    // Constructor
    Siswa(String nama, int umur, String kelas) {
        this.nama = nama;
        this.umur = umur;
        this.kelas = kelas;
    }

    // Method
    void perkenalan() {
        System.out.println("Halo, saya " + nama);
        System.out.println("Umur " + umur + " tahun");
        System.out.println("Kelas " + kelas);
    }
}

🔨 Membuat Object dari Class

// 2. Buat Object di main()
public class Main {
    public static void main(String[] args) {

        // Buat object siswa1
        Siswa siswa1 = new Siswa("Budi", 17, "XI-RPL");
        siswa1.perkenalan();

        // Buat object siswa2
        Siswa siswa2 = new Siswa("Ani", 16, "XI-RPL");
        siswa2.perkenalan();
    }
}

// Output:
// Halo, saya Budi
// Umur 17 tahun
// Kelas XI-RPL
// Halo, saya Ani
// Umur 16 tahun
// Kelas XI-RPL

📌 Method dengan Return Value

Method bisa mengembalikan nilai (bukan hanya mencetak):

class Calculator {
    // Method dengan return (mengembalikan nilai)
    int tambah(int a, int b) {
        return a + b;
    }

    int kurang(int a, int b) {
        return a - b;
    }
}

// Penggunaan di main()
Calculator calc = new Calculator();
int hasil = calc.tambah(10, 5);
System.out.println("Hasil: " + hasil); // Output: 15

📌 Encapsulation (Private & Getter/Setter)

Data dalam class bisa dibuat private (hanya bisa diakses dari dalam class) dan diakses melalui getter/setter.

class Account {
    // Atribut private
    private String nama;
    private double saldo;

    // Constructor
    Account(String nama, double saldo) {
        this.nama = nama;
        this.saldo = saldo;
    }

    // Getter (mengambil data)
    public String getNama() {
        return nama;
    }

    // Setter (mengubah data)
    public void setNama(String nama) {
        this.nama = nama;
    }
}

✏️ Latihan PBO

Buatlah class untuk:

"Class Buku dengan atribut: judul, penulis, tahunTerbit dan method: tampilkanInfo()"

class Buku {
    String judul;
    String penulis;
    int tahunTerbit;

    Buku(String judul, String penulis, int tahunTerbit) {
        this.judul = judul;
        this.penulis = penulis;
        this.tahunTerbit = tahunTerbit;
    }

    void tampilkanInfo() {
        System.out.println("Judul: " + judul);
        System.out.println("Penulis: " + penulis);
        System.out.println("Tahun: " + tahunTerbit);
    }
}
