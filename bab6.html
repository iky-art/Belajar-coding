Variabel & Tipe Data

Apa Itu Variabel?

Variabel itu tempat buat nyimpen data di program. Kayak kotak penyimpanan. Kamu bisa isi kotak itu dengan angka, teks, atau nilai benar/salah.

Tipe Data di Java

Tipe Data Fungsi Contoh
String Teks "Budi", "Halo"
int Angka bulat 10, -5, 0
double Angka desimal 3.14, 0.5
boolean Benar/Salah true, false
char Satu huruf 'A', 'z'

Contoh Kode

// Buat variabel String nama = "Budi"; int umur = 17; double tinggi = 168.5; boolean aktif = true; char grade = 'A'; // Tampilkan System.out.println("Nama: " + nama); System.out.println("Umur: " + umur);

Aturan Penamaan Variabel

  • Pakai camelCase: namaSiswa, totalNilai
  • Jangan mulai dengan angka
  • Jangan pakai kata kunci Java (class, public, dll)
  • Pakai nama yang jelas biar gampang dibaca

Latihan

Buat variabel untuk:

"Nama lengkap, umur, dan status lulus"

String namaLengkap = "Budi Santoso"; int umur = 17; boolean lulus = true;
