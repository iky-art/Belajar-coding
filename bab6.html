Variabel & Tipe Data

📦 Variabel = Kotak Penyimpanan

Variabel adalah tempat menyimpan data di memori komputer. Kayak kotak yang bisa diisi berbagai macam barang. Setiap kotak punya nama dan isi.

📌 Analogi Variabel

  • Kotak = Variabel
  • Label nama = Nama variabel
  • Isi kotak = Nilai/data
  • Jenis barang = Tipe data

📌 Tipe Data Dasar di Java

Tipe DataFungsiContoh NilaiUkuran
StringTeks"Budi", "Halo", "RPL"-
intAngka bulat10, -5, 0, 10004 byte
doubleAngka desimal3.14, 0.5, -2.78 byte
booleanBenar/Salahtrue, false1 bit
charSatu huruf'A', 'z', '5'2 byte

💻 Cara Membuat Variabel

// Format: tipeData namaVariabel = nilai;

// String (teks) - pakai tanda petik dua
String namaSiswa = "Budi Santoso";
String alamat = "Jl. Mawar No. 10";

// int (angka bulat) - tanpa tanda petik
int umur = 17;
int jumlahSaudara = 2;

// double (angka desimal)
double tinggiBadan = 168.5;
double ipk = 3.85;

// boolean (benar/salah)
boolean isAktif = true;
boolean isLulus = false;

// char (satu huruf) - pakai tanda petik satu
char grade = 'A';
char jenisKelamin = 'L';

💻 Menampilkan Isi Variabel

// Menampilkan variabel ke layar
System.out.println("Nama: " + namaSiswa);
System.out.println("Umur: " + umur + " tahun");
System.out.println("Tinggi: " + tinggiBadan + " cm");
System.out.println("Aktif: " + isAktif);
System.out.println("Grade: " + grade);

// Output yang dihasilkan:
// Nama: Budi Santoso
// Umur: 17 tahun
// Tinggi: 168.5 cm
// Aktif: true
// Grade: A

📌 Aturan Penamaan Variabel

  • Harus dimulai dengan huruf atau garis bawah (_)
  • Boleh mengandung angka, tapi tidak boleh di awal
  • Gunakan camelCase: namaSiswa, totalNilai
  • Nama variabel case sensitive: nama ≠ Nama
  • Jangan pakai kata kunci Java: class, public, static
// Contoh PENAMAAN YANG SALAH
// int 1nama = 10; // ❌ Tidak boleh dimulai angka
// int class = 5; // ❌ Kata kunci Java
// String nama-siswa = "Budi"; // ❌ Pakai strip (-)

// Contoh PENAMAAN YANG BENAR
int nama1 = 10; // ✅ Boleh ada angka di akhir
int _nilai = 5; // ✅ Boleh diawali garis bawah
String namaSiswa = "Budi"; // ✅ camelCase

📊 Konversi Tipe Data

Kadang kita perlu mengubah satu tipe data ke tipe lain:

// Konversi dari int ke double (otomatis)
int angkaBulat = 10;
double angkaDesimal = angkaBulat; // 10.0

// Konversi dari double ke int (harus dipaksa)
double nilaiDesimal = 3.7;
int nilaiBulat = (int) nilaiDesimal; // 3 (desimal dihilangkan)

✏️ Latihan Variabel

Buatlah variabel untuk menyimpan:

"Nama lengkap, umur, tinggi badan, dan status menikah"

String namaLengkap = "Budi Santoso";
int umur = 17;
double tinggiBadan = 168.5;
boolean isMenikah = false;
