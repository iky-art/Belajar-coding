🗄️ Database = Tempat Penyimpanan Data

Basis Data (Database) adalah tempat menyimpan data secara terstruktur. Kayak lemari arsip digital! SQL (Structured Query Language) adalah bahasa untuk berkomunikasi dengan database.

📌 Analogi Database

  • Database = Lemari arsip
  • Tabel = Folder di dalam lemari
  • Row/Record = Satu lembar data
  • Column/Field = Kolom data (nama, umur, dll)

📌 Tabel dalam Database

nis (INT)nama (VARCHAR)kelas (VARCHAR)umur (INT)

nis = Primary Key (identitas unik setiap data)

💻 Contoh SQL Lengkap

-- 1. Membuat Database
CREATE DATABASE sekolah;

-- 2. Menggunakan Database
USE sekolah;

-- 3. Membuat Tabel
CREATE TABLE siswa (
    nis INT PRIMARY KEY,
    nama VARCHAR(50) NOT NULL,
    kelas VARCHAR(10),
    umur INT
);

-- 4. Menambah Data (INSERT)
INSERT INTO siswa VALUES (101, 'Budi', 'XI-RPL', 17);
INSERT INTO siswa VALUES (102, 'Ani', 'XI-RPL', 16);
INSERT INTO siswa VALUES (103, 'Caca', 'XI-RPL', 17);

-- 5. Mengambil Data (SELECT)
SELECT * FROM siswa; -- Tampilkan semua
SELECT nama, kelas FROM siswa; -- Tampilkan nama & kelas saja
SELECT * FROM siswa WHERE umur > 16; -- Filter umur > 16

-- 6. Mengubah Data (UPDATE)
UPDATE siswa SET nama = 'Budi Santoso' WHERE nis = 101;

-- 7. Menghapus Data (DELETE)
DELETE FROM siswa WHERE nis = 103;

-- 8. Menghapus Tabel (DROP)
DROP TABLE siswa;

-- 9. Menghapus Database
DROP DATABASE sekolah;

🎯 Tugas Akhir - Mini Project

Buatlah database sederhana untuk Sistem Perpustakaan:

  1. Buat database perpustakaan
  2. Buat tabel buku (id_buku, judul, penulis, stok)
  3. Buat tabel anggota (id_anggota, nama, alamat)
  4. Buat tabel peminjaman (id_pinjam, id_buku, id_anggota, tgl_pinjam)
  5. Tambahkan 3 data buku, 3 data anggota, dan 2 data peminjaman
  6. Tampilkan semua data dengan SELECT
-- 1. Buat Database
CREATE DATABASE perpustakaan;
USE perpustakaan;

-- 2. Buat Tabel Buku
CREATE TABLE buku (
    id_buku INT PRIMARY KEY,
    judul VARCHAR(100),
    penulis VARCHAR(50),
    stok INT
);

-- 3. Buat Tabel Anggota
CREATE TABLE anggota (
    id_anggota INT PRIMARY KEY,
    nama VARCHAR(50),
    alamat VARCHAR(100)
);

-- 4. Buat Tabel Peminjaman
CREATE TABLE peminjaman (
    id_pinjam INT PRIMARY KEY,
    id_buku INT,
    id_anggota INT,
    tgl_pinjam DATE
);

-- 5. Tambah Data Buku
INSERT INTO buku VALUES (1, 'Pemrograman Java', 'Budi', 5);
INSERT INTO buku VALUES (2, 'Belajar SQL', 'Ani', 3);
INSERT INTO buku VALUES (3, 'HTML & CSS', 'Caca', 4);

-- 6. Tambah Data Anggota
INSERT INTO anggota VALUES (1, 'Dedi', 'Jl. Mawar No. 1');
INSERT INTO anggota VALUES (2, 'Eka', 'Jl. Melati No. 2');
INSERT INTO anggota VALUES (3, 'Fina', 'Jl. Anggrek No. 3');

-- 7. Tambah Data Peminjaman
INSERT INTO peminjaman VALUES (1, 1, 1, '2026-01-10');
INSERT INTO peminjaman VALUES (2, 2, 2, '2026-01-12');

-- 8. Tampilkan Semua Data
SELECT * FROM buku;
SELECT * FROM anggota;
SELECT * FROM peminjaman;
