Apa Itu Database?

Database itu tempat nyimpen data secara terstruktur. Kayak lemari arsip gitu, tapi versi digital.

SQL adalah bahasa yang dipakai buat ngobrol sama database.

Perintah SQL Dasar

Perintah Fungsi
CREATE DATABASE Bikin database baru
CREATE TABLE Bikin tabel
INSERT INTO Tambah data
SELECT Ambil data
UPDATE Ubah data
DELETE Hapus data

Contoh SQL

-- Bikin database CREATE DATABASE sekolah; -- Bikin tabel siswa CREATE TABLE siswa ( nis INT PRIMARY KEY, nama VARCHAR(50), kelas VARCHAR(10) ); -- Tambah data INSERT INTO siswa VALUES (101, 'Budi', 'XI-RPL'); INSERT INTO siswa VALUES (102, 'Ani', 'XI-RPL'); -- Ambil data SELECT * FROM siswa; -- Hasil: 101 | Budi | XI-RPL -- 102 | Ani | XI-RPL -- Ubah data UPDATE siswa SET nama = 'Budi Santoso' WHERE nis = 101; -- Hapus data DELETE FROM siswa WHERE nis = 102;

Relasi Tabel

SISWA 1 ---- M NILAI (nis, nama, kelas) (id, nis, mapel, nilai)

Baca: Satu siswa bisa punya banyak nilai

Latihan

Buat query SQL untuk:

"Membuat tabel 'buku' dengan id_buku, judul, penulis"

CREATE TABLE buku ( id_buku INT PRIMARY KEY, judul VARCHAR(100), penulis VARCHAR(50) );

Tugas Akhir

Buat database untuk Sistem Perpustakaan:

  1. Buat database perpustakaan
  2. Buat tabel buku (id_buku, judul, penulis, stok)
  3. Buat tabel anggota (id_anggota, nama, alamat)
  4. Buat tabel peminjaman (id_pinjam, id_buku, id_anggota, tgl_pinjam)
  5. Masukkan 3 data ke setiap tabel
  6. Tampilkan semua data
CREATE DATABASE perpustakaan; USE perpustakaan; CREATE TABLE buku ( id_buku INT PRIMARY KEY, judul VARCHAR(100), penulis VARCHAR(50), stok INT ); CREATE TABLE anggota ( id_anggota INT PRIMARY KEY, nama VARCHAR(50), alamat VARCHAR(100) ); CREATE TABLE peminjaman ( id_pinjam INT PRIMARY KEY, id_buku INT, id_anggota INT, tgl_pinjam DATE ); INSERT INTO buku VALUES (1, 'Java Dasar', 'Budi', 5); INSERT INTO buku VALUES (2, 'SQL', 'Ani', 3); INSERT INTO buku VALUES (3, 'HTML', 'Caca', 4); INSERT INTO anggota VALUES (1, 'Dedi', 'Jl. Mawar 1'); INSERT INTO anggota VALUES (2, 'Eka', 'Jl. Melati 2'); INSERT INTO anggota VALUES (3, 'Fina', 'Jl. Anggrek 3'); INSERT INTO peminjaman VALUES (1, 1, 1, '2026-01-10'); INSERT INTO peminjaman VALUES (2, 2, 2, '2026-01-12'); SELECT * FROM buku; SELECT * FROM anggota; SELECT * FROM peminjaman;
