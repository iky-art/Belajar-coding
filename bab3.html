🌐 HTML = Kerangka Website

HTML (HyperText Markup Language) adalah bahasa untuk membuat struktur halaman web. Kayak kerangka bangunan.

📌 Struktur Dasar HTML

<!DOCTYPE html>
<html>
    <head>
        <title>Judul Halaman</title>
    </head>
    <body>
        <h1>Halo Dunia!</h1>
        <p>Ini paragraf pertama saya.</p>
    </body>
</html>

🏷️ Tag HTML yang Sering Dipakai

TagFungsiContoh
<h1> - <h6>Heading (judul)<h1>Judul Utama</h1>
<p>Paragraf<p>Teks paragraf</p>
<a>Link<a href="url">Teks Link</a>
<img>Gambar<img src="foto.jpg">
<div>Kotak / pembungkus<div>Konten</div>
<ul>, <ol>Daftar<ul><li>Item</li></ul>
<br>Baris baruTeks<br>baris baru
<hr>Garis horizontal<hr>

🎯 Contoh HTML Lengkap

<!DOCTYPE html>
<html>
    <head>
        <title>Profil Saya</title>
    </head>
    <body>
        <h1>Selamat Datang</h1>
        <p>Nama saya <strong>Budi</strong>.</p>
        <p>Saya siswa RPL kelas 11.</p>
        <img src="foto.jpg" alt="Foto Saya" width="200">
        <br>
        <a href="https://instagram.com">Follow Instagram Saya</a>
    </body>
</html>

✏️ Latihan HTML

Buatlah struktur HTML dengan:

"Judul 'Profil Saya', 2 paragraf, 1 gambar, dan 1 link"

<!DOCTYPE html>
<html>
    <head>
        <title>Profil Saya</title>
    </head>
    <body>
        <h1>Profil Saya</h1>
        <p>Halo, nama saya Budi.</p>
        <p>Saya siswa RPL kelas 11.</p>
        <img src="foto.jpg" alt="Foto Saya">
        <a href="https://instagram.com">Instagram Saya</a>
    </body>
</html>
