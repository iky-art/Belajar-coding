Apa Itu HTML?

HTML itu singkatan dari HyperText Markup Language. Ini bahasa yang dipakai buat bikin struktur halaman web. Kayak kerangka rumah gitu.

Struktur Dasar HTML

<!DOCTYPE html> <html>     <head>         <title>Judul Halaman</title>     </head>     <body>         <h1>Halo Dunia</h1>         <p>Ini paragraf pertama.</p>     </body> </html>

Tag HTML yang Sering Dipakai

Tag Fungsi
<h1> - <h6> Judul (h1 paling besar)
<p> Paragraf
<a> Link
<img> Gambar
<div> Kotak pembungkus
<ul> <ol> Daftar (bullet atau nomor)

Latihan

Buat struktur HTML dengan:

"Judul 'Profil Saya', satu paragraf, satu gambar"

<!DOCTYPE html> <html>     <head>         <title>Profil Saya</title>     </head>     <body>         <h1>Profil Saya</h1>         <p>Nama saya Budi, siswa RPL.</p>         <img src="foto.jpg" alt="Foto">     </body> </html>
