CSS Dasar (Mempercantik)

← Bab 3 🏠 Home Bab 5 →

🎨 CSS = Makeup Website

CSS (Cascading Style Sheets) digunakan untuk mempercantik tampilan website. Kayak baju dan makeup!

📌 Cara Menulis CSS

/* Cara 1: Di dalam tag style */
<style>
    body {
        background-color: #f0f0f0;
    }
</style>

/* Cara 2: Di file terpisah (style.css) */
h1 {
    color: blue;
    font-size: 32px;
}

🎯 Property CSS Dasar

PropertyFungsiNilai Contoh
colorWarna teksred, #ff0000, rgb(255,0,0)
background-colorWarna latarblue, #0000ff
font-sizeUkuran teks16px, 2em, 1.5rem
marginJarak luar10px, auto, 10px 20px
paddingJarak dalam15px, 5%
borderGaris tepi1px solid black
text-alignRata tekscenter, left, right
font-weightTebal teksbold, normal, 700

💻 Contoh CSS Lengkap

/* Style untuk semua h1 */
h1 {
    color: #2d3748;
    font-size: 36px;
    text-align: center;
    margin-bottom: 20px;
}

/* Style untuk class .btn */
.btn {
    background: #4fc3f7;
    color: white;
    padding: 10px 20px;
    border: none;
    border-radius: 30px;
    cursor: pointer;
}

✏️ Latihan CSS

Buatlah CSS untuk:

"Buat h1 berwarna biru, ukuran 40px, dan rata tengah"

h1 {
    color: blue;
    font-size: 40px;
    text-align: center;
}
