Apa Itu CSS?

CSS itu Cascading Style Sheets. Dipakai buat mempercantik tampilan website. Kalau HTML itu kerangka, CSS itu cat dan dekorasinya.

Cara Nulis CSS

/* Di dalam tag style */ <style>     body {         background-color: #f0f0f0;     } </style> /* Atau di file terpisah */ h1 {     color: blue;     font-size: 32px; }

Property CSS Dasar

Property Fungsi Contoh Nilai
color Warna teks red, #ff0000
background-color Warna latar blue, #0000ff
font-size Ukuran teks 16px, 2em
margin Jarak luar 10px, auto
padding Jarak dalam 15px
border Garis tepi 1px solid black

Latihan

Buat CSS untuk:

"Buat semua h1 berwarna biru dan ukuran 40px"

h1 {     color: blue;     font-size: 40px; }
