Apa Itu Logika?

Logika adalah cara berpikir yang masuk akal. Dalam pemrograman, logika adalah dasar dari semua keputusan yang diambil komputer.

Contoh gampangnya:
Jika hujan, maka bawa payung.
Jika lapar, maka makan.

Contoh Logika di Kode

// Jika nilai lebih dari 75, maka lulus if (nilai >= 75) { System.out.println("Lulus"); } else { System.out.println("Remedial"); }

Operator Logika yang Sering Dipakai

Operator Arti Contoh
&& Dan nilai >= 75 && absen >= 80
|| Atau nilai >= 90 || nilai >= 85
! Tidak !lulus

Latihan

Buat logika untuk:

"Jika umur lebih dari 17, maka boleh bikin SIM"

if (umur > 17) { System.out.println("Boleh bikin SIM"); } else { System.out.println("Belum cukup umur"); }
