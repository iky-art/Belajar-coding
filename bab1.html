Apa Itu Logika?

🏠 Home Bab 2 →

🧠 Logika adalah Akal Sehat

Logika adalah cara berpikir yang masuk akal. Dalam pemrograman, logika adalah dasar dari semua keputusan yang dibuat komputer.

📌 Contoh Logika Sehari-hari

  • Jika hujan, maka bawa payung
  • Jika lapar, maka makan
  • Jika nilai ≥ 75, maka lulus

💻 Logika dalam Kode

// Logika: Jika nilai >= 75 maka LULUS
if (nilai >= 75) {
    System.out.println("LULUS!");
} else {
    System.out.println("REMEDIAL");
}

✏️ Latihan Logika

Buatlah logika untuk:

"Jika umur lebih dari 17 tahun, maka bisa membuat SIM"

if (umur > 17) {
    System.out.println("Bisa membuat SIM");
} else {
    System.out.println("Belum cukup umur");
}
