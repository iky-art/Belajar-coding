Percabangan (IF-ELSE)

← Bab 6 🏠 Home Bab 8 →

🔀 Percabangan = Mengambil Keputusan

Percabangan digunakan untuk membuat keputusan dalam program. Kayak memilih jalan di persimpangan! Program akan menjalankan kode yang berbeda tergantung kondisi yang diberikan.

📌 Struktur IF-ELSE

if (kondisi) {
    // Kode jika kondisi BENAR
} else {
    // Kode jika kondisi SALAH
}

Kondisi adalah ekspresi yang menghasilkan true (benar) atau false (salah).

📌 Operator Perbandingan

OperatorArtiContoh
==Sama dengannilai == 100
!=Tidak samanilai != 0
>Lebih besarumur > 17
<Lebih kecilnilai < 75
>=Lebih besar atau samanilai >= 75
<=Lebih kecil atau samanilai <= 100

💻 Contoh IF-ELSE Sederhana

int nilai = 85;

if (nilai >= 75) {
    System.out.println("Selamat! Anda LULUS");
} else {
    System.out.println("Mohon ikuti REMEDIAL");
}

// Output: Selamat! Anda LULUS

📌 IF-ELSE IF (Banyak Kondisi)

Untuk mengecek lebih dari 2 kondisi, gunakan else if:

int nilai = 85;

if (nilai >= 90) {
    System.out.println("Grade A - Sangat Baik");
} else if (nilai >= 75) {
    System.out.println("Grade B - Baik");
} else if (nilai >= 60) {
    System.out.println("Grade C - Cukup");
} else {
    System.out.println("Grade D - Kurang");
}

// Output: Grade B - Baik

📌 Operator Logika (&& dan ||)

Untuk menggabungkan beberapa kondisi:

OperatorArtiContoh
&&DAN (semua harus benar)nilai >= 75 && absen >= 80
||ATAU (salah satu benar)nilai >= 90 || nilai >= 85
!TIDAK (kebalikan)!lulus
int nilai = 85;
int absen = 90;

// Cek: nilai >= 75 DAN absen >= 80
if (nilai >= 75 && absen >= 80) {
    System.out.println("Lulus dengan baik");
} else {
    System.out.println("Tidak lulus");
}

// Output: Lulus dengan baik

📌 Switch Case (Alternatif IF-ELSE)

Untuk kondisi dengan banyak nilai tetap:

int hari = 3;
String namaHari;

switch (hari) {
    case 1:
        namaHari = "Senin";
        break;
    case 2:
        namaHari = "Selasa";
        break;
    case 3:
        namaHari = "Rabu";
        break;
    default:
        namaHari = "Hari tidak valid";
}

System.out.println("Hari: " + namaHari);
// Output: Hari: Rabu

✏️ Latihan Percabangan

Buatlah program dengan:

"Jika nilai >= 80 tampilkan 'A', jika >= 70 'B', jika >= 60 'C', selain itu 'D'"

int nilai = 75;

if (nilai >= 80) {
    System.out.println("A");
} else if (nilai >= 70) {
    System.out.println("B");
} else if (nilai >= 60) {
    System.out.println("C");
} else {
    System.out.println("D");
} // Output: B
