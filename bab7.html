Percabangan (IF-ELSE)

← Bab 6 Home Bab 8 →

Apa Itu Percabangan?

Percabangan dipakai buat bikin keputusan di program. Kayak kamu mau pilih jalan A atau B di persimpangan.

Struktur IF-ELSE

if (kondisi) { // Kode jalan kalau kondisi benar } else { // Kode jalan kalau kondisi salah }

Contoh

int nilai = 85; if (nilai >= 75) { System.out.println("Lulus"); } else { System.out.println("Remedial"); } // Output: Lulus

IF-ELSE IF (Banyak Kondisi)

int nilai = 85; if (nilai >= 90) { System.out.println("A"); } else if (nilai >= 75) { System.out.println("B"); } else if (nilai >= 60) { System.out.println("C"); } else { System.out.println("D"); } // Output: B

Latihan

Buat percabangan untuk:

"Jika nilai >= 80 = A, >= 70 = B, >= 60 = C, selain itu D"

int nilai = 75; if (nilai >= 80) { System.out.println("A"); } else if (nilai >= 70) { System.out.println("B"); } else if (nilai >= 60) { System.out.println("C"); } else { System.out.println("D"); }
