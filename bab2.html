Apa Itu Algoritma?

← Bab 1 🏠 Home Bab 3 →

📋 Algoritma = Langkah-langkah

Algoritma adalah urutan langkah-langkah logis untuk menyelesaikan masalah. Kayak resep masakan!

📌 Contoh Algoritma Membuat Kopi

  1. Masukkan air ke panci
  2. Rebus air sampai mendidih
  3. Masukkan kopi ke gelas
  4. Tuang air panas ke gelas
  5. Tambahkan gula
  6. Aduk sampai rata
  7. Kopi siap diminum

📌 Ciri-ciri Algoritma yang Baik

  • Jelas - Setiap langkah mudah dipahami
  • Urut - Ada urutan yang logis
  • Terbatas - Ada akhir (tidak berputar terus)
  • Efektif - Bisa dijalankan

💻 Algoritma dalam Kode

// Algoritma menghitung luas persegi panjang
// 1. Tentukan panjang
int panjang = 10;
// 2. Tentukan lebar
int lebar = 5;
// 3. Hitung luas (panjang × lebar)
int luas = panjang * lebar;
// 4. Tampilkan hasil
System.out.println("Luas = " + luas);

📊 Representasi Algoritma

Algoritma bisa ditulis dalam:

  • Deskripsi - Tulisan biasa
  • Flowchart - Diagram alir
  • Pseudocode - Mirip kode tapi bahasa manusia
// Pseudocode menghitung rata-rata
INPUT nilai1, nilai2, nilai3
COMPUTE total = nilai1 + nilai2 + nilai3
COMPUTE rata = total / 3
OUTPUT rata

✏️ Latihan Algoritma

Buatlah algoritma untuk:

"Menghitung rata-rata 3 nilai ujian"

// 1. Siapkan 3 nilai
int nilai1 = 80;
int nilai2 = 90;
int nilai3 = 75;
// 2. Jumlahkan semua nilai
int total = nilai1 + nilai2 + nilai3;
// 3. Bagi dengan jumlah data (3)
double rata = total / 3.0;
// 4. Tampilkan hasil
System.out.println("Rata-rata = " + rata);
