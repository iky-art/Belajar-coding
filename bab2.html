Apa Itu Algoritma?

Algoritma adalah urutan langkah-langkah untuk menyelesaikan masalah. Kayak resep masakan. Kalau kamu mau bikin kopi, ada langkah-langkahnya kan?

Contoh Algoritma Bikin Kopi

  1. Masukkan air ke panci
  2. Rebus air sampai mendidih
  3. Siapkan gelas dan kopi
  4. Tuang air panas ke gelas
  5. Aduk sampai rata
  6. Kopi siap diminum

Algoritma di Kode

// Algoritma menghitung luas persegi panjang // 1. Siapkan panjang int panjang = 10; // 2. Siapkan lebar int lebar = 5; // 3. Hitung luas int luas = panjang * lebar; // 4. Tampilkan hasil System.out.println("Luas = " + luas);

Ciri Algoritma yang Baik

  • Jelas - gampang dimengerti
  • Urut - ada langkah yang berurutan
  • Ada akhir - nggak muter-muter terus
  • Bisa dijalankan - masuk akal

Latihan

Buat algoritma untuk:

"Menghitung rata-rata dari 3 nilai"

// 1. Siapkan 3 nilai int nilai1 = 80; int nilai2 = 90; int nilai3 = 75; // 2. Jumlahkan int total = nilai1 + nilai2 + nilai3; // 3. Bagi dengan 3 double rata = total / 3.0; // 4. Tampilkan System.out.println("Rata-rata = " + rata);
